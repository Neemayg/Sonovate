# Frontend rules

- Keep API access in a clear service/client layer; do not embed secrets in browser code.
- Represent loading, empty, success, and error states.
- Label anomaly scores and risk indicators clearly; do not imply medical/engineering certainty.
- Show the timestamp, machine, and context associated with each prediction.
- Do not hardcode model outputs or demo metrics as real data. Mark fixtures and demo data clearly.
- Keep accessible labels, keyboard interaction, and responsive layouts.
